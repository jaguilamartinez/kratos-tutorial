# Appendices

The chapters teach Kratos in execution order. These appendices collect subjects that cut across every chapter and deserve a second, deeper pass.

- [Appendix A — ProjectParameters in depth](A_project_parameters/README.md) explains how configuration reaches the code that consumes it, how defaults and validation actually work, and how to review a case without guessing.
- [Appendix B — FlowGraph](B_flowgraph/README.md) explains how to author Kratos workflows visually and how to validate the generated multistage configuration.

Read Appendix A before Appendix B. FlowGraph makes the configuration structure visible, but it does not replace the need to understand the resulting Kratos parameters.
